A running list of things worth returning to. Some are about software; some are about attention, typography, or the craft of making a small thing well.

### Systems & Software

- **A Philosophy of Software Design** — John Ousterhout. A short, opinionated argument for deep modules and quiet interfaces.
- **The Art of UNIX Programming** — Eric S. Raymond. Still the best description of the small-tool instinct.
- **Designing Data-Intensive Applications** — Martin Kleppmann. The book I recommend whenever someone asks what a database is really doing.
- **Crafting Interpreters** — Robert Nystrom. A patient, generous introduction to language implementation.

### Interfaces & Typography

- **The Elements of Typographic Style** — Robert Bringhurst. The reference for measure, rhythm, and restraint.
- **Thinking with Type** — Ellen Lupton. A clear, visual introduction to the vocabulary of type.
- **The Humane Interface** — Jef Raskin. Dated in places, still useful for asking what an interface is *for*.
- **Refactoring UI** — Adam Wathan and Steve Schoger. Practical notes on hierarchy, spacing, and contrast.

### Attention & Practice

- **Deep Work** — Cal Newport. A useful vocabulary for protecting long stretches of concentration.
- **The Shallows** — Nicholas Carr. A cautionary book about what the web does to reading.
- **Bird by Bird** — Anne Lamott. Not about code, but the best book on shipping imperfect work.
- **Shop Class as Soulcraft** — Matthew B. Crawford. A case for caring about the material.

### On the Web

- [The Grug Brained Developer](https://grugbrain.dev/) — a funny, accurate essay about complexity.
- [Writing for Interfaces](https://www.nngroup.com/) — the Nielsen Norman archive on clear language.
- [MDN Web Docs](https://developer.mozilla.org/) — the reference I open most often.
- [SQLite Documentation](https://sqlite.org/docs.html) — unusually readable for a database manual.
